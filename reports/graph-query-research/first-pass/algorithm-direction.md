# Agreed algorithm direction

User endorsed proposed analysis/drawing stack after first-pass research. This establishes direction, not measured usefulness/performance, dependency adoption or a complete implementation contract.

## Analysis

- Typed outgoing/incoming adjacency indexes support BFS/DFS reachability, prerequisite ancestry and sourced explanation paths. Preserve field/direction semantics; a single path does not prove an entire AND combination.
- Reuse iterative Kosaraju SCC analysis where applicable. Interpret prerequisite cycles, route revisits and resource feedback separately. Condensed regions never erase raw declarations.
- Start graph-wide discovery with inverted feature indexes and bounded typed path joins. Discover candidates before pair drill-down; no manual exhaustive comparison workflow. Retain shared evidence, differing branches and changed roles.
- Add cycle-aware prerequisite closures and explicit AND-junction discovery for shared foundations/combinations. Cache/bitset choices follow measurement. Do not flatten inherited dependencies into direct teaching claims or known skills.
- Reuse existing two-state route BFS and opportunity witnesses. Distinguish constituents from combinations without duplicating route engine.
- Rooted path slice: implemented bounded reverse-postorder iterative dominator computation in `native/gd_graph_paths.c` (accepted checkpoint). Original algorithm checked in Cooper/Harvey/Kennedy, [A Simple, Fast Dominance Algorithm](https://www.cs.tufts.edu/~nr/cs257/archive/keith-cooper/dom06.pdf), pp. 5–8 / Figure 3: postorder numbering, reverse-postorder passes, immediate-dominator parent chains, intersect initialized predecessors, repeat to fixed point. Irreducible cycles can require multiple passes; intermediate dominators are not final proofs. NetworkX [current implementation](https://networkx.org/documentation/stable/_modules/networkx/algorithms/dominance.html) independently exposes directed/reachable-only scope. Independent vertex-removal oracle covers 1,536 graph/mask/start/direction cases, plus capacity/budget/cache/reload checks. Directed adapters follow shown arrows; matrix/resource adapters explicitly use undirected incidence, not flow. Mandatory-path proofs are unavailable when no starts are shown or fixed-point work budget is exhausted. Results concern reachable targets in shown projection; missing/filtered routes can change wider conclusions. Root policy and pending paired-bypass/reconvergence scope live in `todo.md`, **Identify mandatory route prefixes and reconvergence**. No performance or product-benefit result claimed. Lengauer–Tarjan only if measured need warrants complexity.
- Shallow WL-inspired structural signatures remain a secondary lens. Learned embeddings, opaque weighted scores and mandatory 2D projection are not first steps. Optional Jaccard/containment scores need a useful relation-lens contract first.

## Drawing and interaction

- Extend existing directed layout toward a Sugiyama-style pipeline: explicit SCC/cycle treatment, semantically defined layers, bounded median/barycentre ordering/local swaps, label-aware coordinates and routed feedback/long/parallel edges.
- Keep prerequisite depth, authored rank and route entry-hop layers distinct. Never silently reinterpret rank or remove feedback edges to force a DAG.
- Retain bounded force layout for nonhierarchical relationship neighbourhoods. Preserve useful positions during expansion. Geometric proximity is not a similarity result.
- Start obstacle-aware lane/port routing with bounded collision checks. Prioritize path continuity, visible arrowheads and avoidance of false node/label incidence. No global edge bundling by default.
- Measure text bounds; use deterministic placement/collision policies and readable distinguishable identities. Analysis visibly changes graph through explicit layers, with compact legend/toggles and redundant text/shape/pattern cues as well as colour.
- Dense overview may later use adjacency/incidence matrices or truthful aggregation with node-link detail. No universal size threshold. Existing noun/verb matrix is not an existing prerequisite matrix.
- Resource flow widths require actual meaningful quantities under explicit semantics; reference counts are not Sankey amounts.
