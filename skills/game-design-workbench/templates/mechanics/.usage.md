# mechanics

Own reusable rules and state transitions. Control variables own configuration values; interactions own case-specific details. One authoritative `gd-rule` body block holds unordered named cases and explicit participant/noun bindings.

Keep raw text editable without agent or conversion. Reuse typed axes/predicates and shared numeric math; actor quantities are not configuration defaults. Explicit `causes` maps every multi-participant callee; one-participant shorthand never guesses by name/type. Direct and invoked effects read the same starting facts. Resolve OTHER after whole expansion; named/ALL preservation remains a constraint. No automatic inheritance, sequential mutation, source winner or repair. Retain missing conditions/outcomes and staging as unknown, not ANY/preserved/zero. Prose explains intent. See installed skill's `native/rules.md` and `native/outcomes.md` for bounded headless checks and limits.

`context_axes` references allowed ordered-context vocabularies from `axes`; omitted/null is unknown, `[]` declares an empty current inventory. Each body case may select ANY or LEFT OPERATOR RIGHT between its own participant names. Preserve order; no implicit contact, actor-state applicability, inheritance or commutativity.
