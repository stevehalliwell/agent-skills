# Mechanics, Dynamics, Aesthetics

Pack: `mda` · version 1
Attribution: Robin Hunicke, Marc LeBlanc, Robert Zubek (2004)

## Scope

Trace a selected rule or intended experience through authored mechanics, runtime-behavior hypotheses, and aesthetics. Systems group mechanics; they are not dynamics.

Use only when this lens is selected. Follow [review operation](../review.md); do not repair source during review.

## Inputs and query support

Roles: `mechanics`, `systems`, `dynamics`, `aesthetics`, `hypotheses`, `experiments`, `observations`. Read actual role mapping and live schema/usage before writing.

Available recipes: `query mda`; `query evidence`; `query records --collection <mapped-alias>`. These are declared-data projections, not automated framework verdicts. Inspect linked bodies for conditions and evidence.

## Original prompts

1. Which specific rule could produce the named behavior, and under which player choices?
2. Working backward from the intended feeling, which behavior would make that intention plausible?
3. Could the same rule produce an opposing experience under another strategy or context?
4. Which link is a supplied design fact, which is an interpretation, and which has observed support?
5. What experience has no declared supporting path? Is the path absent from documentation or absent from the design?
6. What small observation could distinguish the proposed behavior from its strongest competing explanation?

## Missing data and evidence limits

Discuss intention without complete links. Mark disconnected records as unknown/unresolved, not failed experiences. Distinguish empty observations from evidence against a claim.

A declared mechanic–dynamic–aesthetic chain is not causal proof or emotional measurement. The mda recipe inventories declared links; disconnected-path interpretation remains agent work. Do not demand all eight familiar aesthetic labels.

## Fixture application

Inspect crate-pushing, careful-positioning, and deliberate-tension links. Ask whether the authored challenge intention has support beyond prose; observations are empty.
