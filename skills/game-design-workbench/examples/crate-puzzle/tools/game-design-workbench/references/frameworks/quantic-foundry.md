# Published gamer-motivation vocabulary

Pack: `quantic-foundry` · version 1
Attribution: Quantic Foundry, Gamer Motivation Model and 2015 profile-v2 explanation

## Scope

Compare an intended experience with activities that might support interests described by the published multidimensional motivation vocabulary.

Use only when this lens is selected. Follow [review operation](../review.md); do not repair source during review.

## Inputs and query support

Roles: `aesthetics`, `mechanics`, `dynamics`, `challenges`, `hypotheses`, `observations`. Read actual role mapping and live schema/usage before writing.

Available recipes: `query mda`; `query evidence`; `query records --collection <mapped-alias>`. These are declared-data projections, not automated framework verdicts. Inspect linked bodies for conditions and evidence.

Vocabulary: Action: Destruction/Excitement; Social: Competition/Community; Mastery: Challenge/Strategy; Achievement: Completion/Power; Creativity: Discovery/Design; Immersion: Fantasy/Story. These are attributed model labels, not workbench scores.

## Original prompts

1. Which named interest is actually part of the current design intention?
2. What repeated player activity supports that interest rather than merely mentioning it in theme or copy?
3. Could the same mechanic serve different interests through different choices?
4. What tension appears when supporting two intended interests at once?
5. Which interests are deliberately outside scope, with no need to add corresponding features?
6. What play evidence would distinguish the intended appeal from the designer’s preferred interpretation?

## Missing data and evidence limits

Discuss intended interests without surveyed profiles. If no interest is supplied, offer vocabulary as optional hypotheses rather than assigning an audience.

No questionnaire, preference scoring, cohort collection, audience dataset, personality inference, or single player type. Published empirical model does not validate a workbench-specific support claim.

## Fixture application

Deliberate planning plausibly relates to Challenge/Strategy. That is an interpretation to test, not a measured preference profile for puzzle players.
