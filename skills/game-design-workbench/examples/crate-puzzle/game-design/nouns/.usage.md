# nouns

Canonical entity identity and meaning. Resource metadata extends this identity. Keep actor identity across state changes.

`is_actor` classifies this noun without creating another identity. Use boolean `true` for an explicitly identified actor, `false` for an explicitly non-actor concept. Omit when unclassified; absence is not false. Do not infer classification from name, prose, axes or rule participation. Actors are not limited to autonomous characters; classify other world objects deliberately under project policy. Existing noun/state queries include all classifications. No duplicate actor collection or per-actor state list.

Attendant declares `is_actor: null` in schema because optional typed booleans are unsupported; this is not a record default. Native reader enforces supplied boolean type and rejects record null, strings, numbers, collections and duplicate fields. Generic Attendant validation alone does not enforce this semantic type.

`axes` explicitly references applicable typed definitions. Omitted/null means unspecified; `[]` records an empty current inventory, not proof of a complete design. Do not infer applicability from interaction mentions or manufacture combinations as reachable. Axis definitions list known states/units; mechanic/interaction blocks own conditions and effects. Keep unmodeled dimensions explicit in body; do not call a partial list exhaustive.
