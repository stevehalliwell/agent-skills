# interactions

One conditional noun–verb interaction record. Own case-specific conditions, consequences and feedback; reference shared mechanics. One authoritative `gd-rule` body block holds unordered named cases with local participant/noun bindings.

Keep raw text editable without agent or conversion. Use typed predicates/quantity assignments, explicit mapped calls and named/ALL/whole-case OTHER preservation. All effects read immutable starting facts; no source winner, implicit inheritance or last-write-wins. Omitted positive conditions/context/effects stay unspecified; omitted guard creates no exclusion. Retain readable `unknown_conditions`/`unknown_effects` for unmodeled scope. Prose explains intent, not a second executable definition. Native declarations and optional conditional analysis do not execute gameplay. See installed skill's `native/rules.md` and `native/outcomes.md`.

`context_axes` references allowed ordered-context vocabularies from `axes`; omitted/null is unknown, `[]` declares an empty current inventory. Body `context` selects ANY or LEFT OPERATOR RIGHT between case-local participant names. Context definitions do not become actor state; `context_nouns` links do not bind participants or declare operators.
