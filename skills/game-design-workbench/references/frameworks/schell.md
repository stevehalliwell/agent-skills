# Contextual reflective design questions

Pack: `schell` · version 1
Attribution: Jesse Schell, The Art of Game Design: A Book of Lenses

## Scope

Reframe a selected design question through concrete player experience, rules, alternatives, and consequences. This is original reflective guidance, not Schell’s deck.

Use only when this lens is selected. Follow [review operation](../review.md); do not repair source during review.

## Inputs and query support

Roles: `mechanics`, `aesthetics`, `challenges`, `decisions`, `hypotheses`. Read actual role mapping and live schema/usage before writing.

Available recipes: `query decisions`; `query mda`; `query records --collection <mapped-alias>`. These are declared-data projections, not automated framework verdicts. Inspect linked bodies for conditions and evidence.

## Original prompts

1. What does the player need to notice, decide, and feel at this exact moment?
2. Which rule is essential to that experience, and what would change if it were removed?
3. What attractive alternative serves the same intention through a different constraint?
4. What cost appears elsewhere in the design when this local change succeeds?
5. Which assumption is doing the most work in the current argument?
6. What small comparison could expose that assumption before a durable decision?

## Missing data and evidence limits

Start from supplied facts and scoped alternatives. Unknowns become questions/hypotheses, not invented rules. Preserve rejected alternatives and rationale.

No copied lens-card wording, numbering, complete deck, or claim of comprehensive book coverage. Do not use this pack as permission to run other framework reviews.

## Fixture application

Question whether pulling would undermine deliberate placement; retain its prior rejection while exploring a distinct recovery alternative.
