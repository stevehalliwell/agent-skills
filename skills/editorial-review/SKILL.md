# Editorial review

Revise supplied long-form prose without replacing its authorial intent.

## Workflow

1. Establish editorial brief. Identify supplied draft, target channel, intended reader, desired outcome, author voice, and available factual sources. If no draft is supplied, ask for it and wait. Ask for other missing information only when it materially changes revision; otherwise state assumptions. Done when a revisable draft and editorial context are available.
2. Edit complete draft. Improve structure, meaning, phrasing, pacing, clarity, grammar, title, opening, links, calls to action, positioning language, and reader context where relevant to agreed channel. Preserve author intent and voice unless they conflict with clarity, accuracy, or agreed channel fit. Done when the revised draft serves the agreed channel without changing authorial intent.
3. Handle claims. Correct claims only from supplied sources. Flag uncertain or unsupported claims rather than inventing support. Done when factual changes are sourced and remaining claim risks are visible.
4. Return revision. Provide revised draft and concise material-change rationale, including meaningful trade-offs. Done when the user can review both the revised prose and its material changes.

## Rules

- Work on supplied long-form drafts only.
- Do not create first drafts, develop marketing conversion strategy, perform autonomous research, or publish.
- Keep editorial judgment separate from factual approval.
