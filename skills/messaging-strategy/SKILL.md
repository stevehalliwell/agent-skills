# Messaging strategy

Make customer-facing messaging clear, differentiated, credible, and useful for its intended audience.

## Intent

1. Classify explicit intent. Review, audit, or assess means diagnosis; supplied wording plus tweak, rewrite, or alternative means copy directions. If ambiguous, ask whether user wants diagnosis or copy direction before analysis. Done when branch is clear.
2. Establish context. Identify audience, problem, desired outcome, offer, proof, message artifact or page, and conversion action when relevant. Label missing inputs as assumptions. Done when message is judged against stated or assumed context.

## Review branch

Inventory message framing, supporting copy, claims, proof, hierarchy or narrative flow, objections, and calls to action where relevant. Diagnose gaps in audience fit, differentiation, credibility, specificity, action path, and unsupported claims. Present high-impact decisions and next options; wait for direction before rewriting. Done when diagnosis is actionable without unrequested copy.

## Copy-direction branch

1. Present 2–3 viable directions with candidate wording, trade-offs, and recommendation. Do not invent claims, positioning, or proof. Done when the user can choose a direction.
2. Wait for the user's choice, then produce final copy in that direction from supplied facts and approved claims. Do not reopen settled choices merely to seek approval again. Done when the selected direction has usable final copy or a material evidence gap is named.
3. Check final copy against audience, message goal, selected direction, claim support, and requested channel. Correct unsupported claims or intent drift and recheck; leave unresolved proof or product decisions explicit rather than fabricating them. Done when final copy and remaining limits are reviewable.

## Output shapes

```text
Review: <message artifact>

## Audience and message goal
## Message diagnosis
## Proof and claim gaps
## High-impact decisions
## Next options
```

```text
Copy directions: <supplied wording>

1. <direction> — <candidate wording> — <trade-off>
2. <direction> — <candidate wording> — <trade-off>
3. <optional direction> — <candidate wording> — <trade-off>

Recommendation: <direction>
Need from you: choose a direction before final copy.
```

## Rules

- Use this skill for customer-facing messaging, including website copy and SEO/GEO audience relevance; route visual direction or browser implementation to their own workflows.
- Use supplied facts; label assumptions.
- Keep messaging separate from HTML, CSS, CMS, analytics, visual design, and deployment.
- Claims require user, legal, product, or evidence approval.
