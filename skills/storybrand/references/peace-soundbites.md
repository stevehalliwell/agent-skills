# PEACE soundbites

PEACE is an optional StoryBrand deployment layer: five short, repeatable statements that make a customer story easier to recognise across campaign material. Build a complete SB7 BrandScript first. PEACE does not replace SB7 because it does not independently cover authority, plan, CTA, failure, or claim verification.

Source: [StoryBrand Soundbite Strategy training transcript](sources/storybrand-soundbite-strategy-transcript-prose.md).

## Template

1. **Problem** — name one specific customer problem that earns attention.
   - <customer-recognisable problem, in plain language>
   - Test: would the intended customer recognise this as their problem without extra explanation?

2. **Empathy** — show the guide understands the difficulty.
   - <brief, credible acknowledgement of the customer's experience>
   - Keep the organisation in the guide role; do not claim an experience it cannot support.

3. **Answer** — state how the offer helps.
   - <plain description of the offer as an answer to the named problem>
   - Use only supported product capability and differentiation.

4. **Change** — describe the customer's supported transformation.
   - <from current state → to more capable or confident state>
   - This must align with the BrandScript's character transformation and remain an evidence-bound possibility, not an inflated promise.

5. **End result** — show the better future.
   - <specific customer-centred outcome>
   - This must align with the BrandScript's success outcome and credible stakes.

## Use

- Keep the five statements short, plain, and consistent enough to repeat across appropriate touchpoints.
- Check that they form one causal chain: problem → guide empathy → answer → change → end result.
- Treat low cognitive load as a clarity target, not proof that a message will perform or cause a business outcome.
- Test each statement against the BrandScript's confirmed facts, assumptions, and open questions before using it in public copy.
